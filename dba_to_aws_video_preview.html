Identity & Access Management
⊘ Traditional Oracle
Oracle Roles & Profiles
✓ AWS Equivalent
AWS IAM Policies & Roles
Oracle SQL
-- Oracle: Grant role
GRANT dba TO scott;
CREATE PROFILE secure_profile
  LIMIT PASSWORD_LIFE_TIME 90;
→
IAM Policy JSON
{
  "Effect": "Allow",
  "Action": [
    "rds-db:connect"
  ],
  "Resource": "arn:aws:rds-db:*"
}
💡 Pro tip: Least-privilege access, resource-based policies, database auth via IAM tokens.

CloudWatch & Performance Insights
⊘ Traditional Oracle
Oracle AWR / ADDM Reports
✓ AWS Equivalent
Performance Insights + CloudWatch
Oracle AWR
SELECT sql_id, elapsed_time,
       executions
FROM   dba_hist_sqlstat
ORDER  BY elapsed_time DESC;
→
Performance Schema
SELECT digest_text, avg_latency
FROM   performance_schema
         .events_statements_summary
ORDER  BY avg_latency DESC;
💡 Pro tip: Visual query analysis, wait event monitoring — AWR concepts translate directly!

Database Migration
AWS DMS & SCT
⊘ Traditional Oracle
Manual export/import (Data Pump)
✓ AWS Equivalent
AWS Database Migration Service
Oracle Data Pump
expdp system/pwd \
  DIRECTORY=dp_dir \
  DUMPFILE=mydb.dmp \
  FULL=YES
→
AWS DMS CLI
aws dms create-replication-task \
  --migration-type full-load \
  --source-endpoint-arn $SRC \
  --target-endpoint-arn $TGT
💡 Pro tip: Schema Conversion Tool auto-converts Oracle PL/SQL to PostgreSQL — huge career skill!
